# CHROMEWEBSTORE.md 模板

将此模板复制到项目根目录并命名为 `CHROMEWEBSTORE.md`，然后填写各部分。
标记为 `[REQUIRED]` 的字段必须在提交前完成。标记为 `[RECOMMENDED]` 的字段
为可选项，但能提升上架质量和审核通过率。

---
