- 页面加载时，选择菜单应呈中性外观（无红色边框）。
- 选择有效选项必须移除错误状态。
- 选择“占位符”选项（若启用）或在为空时提交，必须触发错误状态。
- CSS 必须使用 `:user-invalid` 伪类进行校验样式。
- CSS 不得使用会立即触发的 `:invalid` 基础伪类。
- 错误状态显示期间，选择框带有 `aria-invalid="true"`；错误出现前或清除后，不带 `aria-invalid="true"`。
- 当选择框带有 `aria-invalid="true"` 时，其无障碍描述包含可见的错误文本。
- 页面加载时，选择框的无障碍描述不包含其错误文本。
