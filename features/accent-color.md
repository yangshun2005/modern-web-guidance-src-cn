# CSS `accent-color` 属性

## 问题

浏览器对 `accent-color` 的渲染方式各不相同。
对于通常绘制在强调色背景之上的指示器（如复选框标记和单选按钮圆点），浏览器可能采用不同的处理方式：
- **Chromium** 和 **Firefox** 通常选择对比鲜明的指示器颜色。
- **Safari** 则可能在浅色模式下保留白色指示器、在深色模式下保留黑色指示器，同时修改其背后的强调色。这种调整并不总能为每种提供的颜色提供足够的对比度，因此请在 Safari 中测试重要的颜色组合，包括浅色和深色两种配色方案。不要假设 Safari 会自动选择对比度最佳的指示器颜色。

## 回退方案

`accent-color` 属性属于渐进增强。
不支持该属性的浏览器会忽略它，并使用其默认的 UI 颜色。
